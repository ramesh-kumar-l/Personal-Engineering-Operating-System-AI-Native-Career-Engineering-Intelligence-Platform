## FACT — Chain (spec §31)

Engineering Activity → Evidence → Achievement → Impact → Career Signal. Activity ≠ Impact.

## FACT — Evidence categories

architecture, scale, reliability, performance, leadership, influence, ambiguity, mentoring, innovation, developer productivity, business/product impact.

## FACT — Staff/Principal signal engine (spec §32)

Identifies evidence and evidence gaps for ownership, ambiguity, architecture, scale, judgment, influence, strategy, mentoring, business impact, operational excellence. Must never invent evidence.

## FACT — Existing precedents

EEP has an `Evidence` schema; the skills platform has an evidence-provenance schema (`19-evidence-provenance-schema.md`) and an `engineering-knowledge-capture` skill that extracts decisions/lessons/limitations from narrative. Neither models career signal.

## CONSTRAINT

Resume/job features (spec §43–44) generate only from verified evidence; nothing invented. Networking data (spec §45) is personal data under [[18-privacy-model]].
